# Hour of Need: time use and household activity analysis

This project uses UK time use diary episodes to examine **when households undertake activities associated with electricity use** and how those patterns differ across household groups. It is designed to inform discussions about time of use tariffs and demand flexibility: a household's ability to shift activities depends on its routines and circumstances.

The notebooks analyse **reported activity timing and duration**, not metered electricity consumption. An activity may involve electricity, but its recorded minutes should not be interpreted as kWh or as a direct estimate of demand.

## Research questions

- When do households participate in selected activities during a weekday?
- How do activity timing and duration vary by household characteristics?
- Which household groups show more concentrated or more sustained activity patterns across the day, daytime, evening and overnight periods?
- How do data driven household clusters compare with household types defined by income, employment and the presence of children?

## Data and workflow

The first notebook expects a tab separated UK time use diary file named `eliddi_episode_long.txt` and a companion activity lookup named `codes.csv`. These input files are **not distributed here**. You need authorised access to the data and the appropriate activity lookup before running the analysis. The notebook joins the diary's primary activity code to the lookup, retains selected energy associated activities reported at home on weekdays, cleans demographic and household fields, and distributes episode durations across the half hour periods they overlap.

The second notebook summarises those periods into household profiles. It calculates participation and timing features, then clusters households using K-medoids with Manhattan distance and a mixture of activity and household characteristics. It examines the resulting groups using descriptive comparisons, representation ratios, stability checks and statistical tests. The third notebook shows how participation changes throughout the day and compares these clusters with household types defined through explicit rules.

The analysis also uses a **load factor style measure**, calculated as the mean activity minutes across bins divided by the maximum for the same household and time window. Here it describes the spread of recorded activity; it is not an electricity load factor calculated from meter readings. Larger values indicate more sustained activity across the window under this definition.

## Running locally

1. Put the authorised `eliddi_episode_long.txt` and `codes.csv` files in the repository directory.
2. Install Jupyter and the Python packages imported by the notebooks:

   ```bash
   python -m pip install jupyter pandas numpy matplotlib seaborn scipy scikit-learn scikit-learn-extra
   ```

3. Start Jupyter from the repository directory:

   ```bash
   jupyter lab
   ```

4. Run `1.0 Data_preprocessing.ipynb`, then `2.0 Analysis_Hour_of_Need.ipynb`, then `3.0 Household_behaviour_analysis.ipynb`.

The preprocessing notebook contains alternative missing value handling steps. Review that choice before a full run, as it affects the analysis sample. The notebooks have not been packaged as a one command pipeline and no dataset or locked dependency versions are supplied.

## Interpretation and scope

The notebook narratives describe morning and evening activity peaks and differences across household groups. These are findings about **surveyed weekday activities selected for this analysis**. They do not establish the time of actual electricity use or prove that households can move an activity in response to a tariff. The weekday, at home and activity code filters also mean that the results do not represent every household activity or day of the week.

Some groupings combine activity timing with household characteristics, so differences between clusters on those same characteristics should be read as descriptions of the groups rather than independent validation. Reassess statistical tests and small group sizes before using individual cluster results in policy or publication.
